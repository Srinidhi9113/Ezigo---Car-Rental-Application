# Ezigo - Car Rental Application

## Introduction
Ezigo Car Rental Service aims to address the inconvenience and inefficiencies associated with traditional car rental processes. The service provides a user-friendly platform that streamlines the entire rental process, from booking to returning the vehicle.

## Installation
To set up the Ezigo Car Rental Service locally, follow these steps:

1. Clone the repository:

``` sh 
git clone https://github.com/Srinidhi9113/Ezigo---Car-Rental-Application.git
cd Ezigo---Car-Rental-Application
```

2. Install dependencies:
```sh
mvn install
```

3. Run the application:
```sh
mvn spring-boot:run
```

## Usage
After setting up the application, you can access it at http://localhost:8080. The platform provides the following functionalities:

* User Registration and Login: Create a new account or log in to an existing one.
*  Search and Browse Vehicles: Search for available vehicles based on location and date.
* Book a Vehicle: Complete the booking process with transparent pricing and flexible options.

## Features
Ezigo Car Rental Service offers several key features to enhance the car rental experience:

* User-friendly Booking System: An intuitive online platform and mobile application for easy booking.
* Diverse Fleet: A wide range of vehicles including economy cars, SUVs, and luxury vehicles.
* Transparent Pricing: Clear and upfront pricing with no hidden fees.
* Flexible Booking Options: Customisable rental periods to fit various schedules.

## Architecture
The Ezigo Car Rental Service uses the Model-View-Controller (MVC) architectural pattern to ensure scalability and maintainability.

* Model: Handles core business logic and data management, including rental fleet database and customer information.
* View: Represents the user interface components, facilitating user interactions.
* Controller: Intermediates between Model and View, processing user input and managing data flow.
